# CampusLens

CampusLens is a campus friction intelligence dashboard built with standard Next.js. It visualizes recurring student complaints, hotspot locations, peak issue periods, model benchmarks, and association rules.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy to Vercel

Import the repository in Vercel or run:

```bash
npx vercel
npx vercel --prod
```

Vercel detects Next.js automatically; no custom build or output settings are required.
